# 需求目录

## 功能需求

- **REQ-001**：支持最多 30 只 A 股代码输入、规范化、去重、校验和批量分析。
- **REQ-002**：支持六种现有全市场筛选预设、参数校验、稳定排序和 TopN 5–30。
- **REQ-003**：Measurement 与 L1–L5 Decision 分离，切档只重判缓存、不联网。
- **REQ-004**：展示结论、分数/证据强度、因子、风险、K 线、仓位计划和历史复盘。
- **REQ-005**：支持自选、持仓成本/股数、浮动盈亏和横向对比。
- **REQ-006**：支持价格、涨跌幅、综合分的边沿触发预警。
- **REQ-007**：支持独立按需资金流；失败不影响核心分析。
- **REQ-008**：支持复制、CSV 导出、使用说明、策略说明和离线自检。
- **REQ-009**：配置跨会话持久化并兼容现有 JSON。
- **REQ-010**：单只失败不终止批量任务；用户可安全停止任务。

## GUI 与交互需求

- **REQ-011**：GUI 使用 PySide6 Widgets，主外壳为 QMainWindow。
- **REQ-012**：QTableView/model/proxy 承载结果、自选、比较和筛选数据。
- **REQ-013**：耗时任务不阻塞 GUI，所有 QWidget 只在主线程更新。
- **REQ-014**：原生标题栏只出现一次应用图标和“股市锦囊”，内容区不重复。
- **REQ-015**：决策强度组件与摘要形成严格水平中轴，控件宽松协调。
- **REQ-016**：所有可见文字统一使用 Microsoft YaHei，字号和间距使用 token。
- **REQ-017**：支持键盘、焦点、tooltip、accessibleName 和颜色冗余表达。
- **REQ-018**：窗口/对话框居中，内容最大宽度居中，常见 DPI/分辨率无关键裁切。

## 科学与防御需求

- **REQ-019**：所有公式、单位、范围、样本要求、缺失处理和模型版本可追溯。
- **REQ-020**：NaN/Inf、负值、零价格、重复/乱序、缺字段和极端值有显式防御。
- **REQ-021**：回测不使用未来数据，并计入成本、基线、样本和限制。
- **REQ-022**：未经统计校准的分数不得描述为收益概率或确定置信度。
- **REQ-023**：所有结果携带数据来源、获取时间、完整度、新鲜度和降级状态。
- **REQ-024**：禁止伪造行情、资金流、建议或测试证据。

## 网络、质量与交付需求

- **REQ-025**：网络有操作 deadline、有限重试、退避抖动、错误分类、限并发和取消语义。
- **REQ-026**：分页不完整、429、5xx、DNS/TLS/超时、截断和字段漂移有合同测试。
- **REQ-027**：需求—设计—工作项—测试—证据追溯率 100%。
- **REQ-028**：格式、lint、类型、测试、覆盖率、GUI、性能、构建和 EXE 自检门禁可复现。
- **REQ-029**：PySide6/PyInstaller/开发依赖精确锁定并完成许可证、安全、SBOM 审查。
- **REQ-030**：发布仍提供批准的 Windows 交付物和 HTML 说明书，并具有回滚路径。
