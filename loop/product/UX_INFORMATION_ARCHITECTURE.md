# UX 信息架构

## 主外壳

```text
Windows 原生标题栏：小图标 + 股市锦囊（仅此一次）
QMainWindow
├─ 主导航：个股分析 / 全市场选股 / 自选与持仓 / 预警 / 回测比较
├─ 决策强度控制台：L1–L5 + 居中摘要
├─ QStackedWidget 中央工作区
├─ 可选 QDockWidget 上下文检查器
└─ QStatusBar：数据源 / 更新时间 / 网络 / 监控 / 免责声明
```

## 页面责任

- 个股分析：输入、批量结果、当前标的证据、仓位与回测。
- 全市场选股：预设/条件、结果表、入选依据。
- 自选与持仓：组合概览、成本股数、横向对比。
- 预警：规则、监控状态、边沿触发说明。
- 回测比较：可信度回测、五档比较、独立资金流。

## 布局原则

- 顶部只保留一级导航和当前页关键控制，采用 16–24 DIP 组间距与 44–48 DIP 控件高度；不把所有工具压进一条窄带。
- 主从数据用 QSplitter；辅助筛选/编辑用 Dock，不把核心内容全部 Dock 化。
- 表格行选择联动中间证据和右侧检查器，避免同一摘要重复三次。
- 页面标题描述当前任务或标的，不重复主导航文字和产品名。
- 宽屏限制内容最大宽度；窄桌面折叠次要 Dock/动作，不缩小关键控件。
- 每个页面的空、加载、部分、错误、降级、停止和全失败状态均有明确文案与可操作元素，规格见下节《页面状态规格》。
- “工作模式”和“决策强度”使用两个独立但同网格的控制组；标题、选项与摘要分别对齐，禁止把两个标题挤在同一组选项前。

## 页面状态规格

七个规范状态：`空 empty`（无输入/无数据）、`加载中 loading`（任务进行中）、`部分 partial`（部分成功，其余不可用但不影响已得结果）、`错误 error`（本次操作失败但可重试）、`降级 degraded`（成功但基于受限/过期数据，需要角标提示）、`已停止 stopped`（用户主动取消）、`全部失败 all-failed`（页面级不可用）。下表按页面分别给出每个状态的文案基调与可操作元素（affordance）；最终用户可见文案由实现该页面的工作项细化措辞，本表是文案基调与可操作元素的机器可追溯契约，替代原先的 7 态枚举列表。红/绿/琥珀语义与其对比度见 `UI_DESIGN_SYSTEM.md` 颜色一节与 `tokens.json`。

### 个股分析（WI-011）

| 状态 | 文案基调 | 可操作元素 |
|---|---|---|
| 空 | 请输入 1–30 个 A 股代码开始分析 | 输入框聚焦 + 帮助/示例入口 |
| 加载中 | 正在分析 N/30 只标的… | 确定态进度 + “停止”按钮可用 |
| 部分 | 30 只中 X 只失败，已展示其余 Y 只结果 | 失败清单可展开 + 单只“重试” |
| 错误 | 本次分析失败：〈分类原因〉 | “重试”按钮 + 复制错误详情 |
| 降级 | 历史/资金流数据暂不可用，结论仍基于可得数据生成 | 结果区“降级”角标 + tooltip 说明缺失项 |
| 已停止 | 已停止，已完成 N/30，可查看已得结果 | “继续分析剩余”按钮，已得结果照常可交互 |
| 全部失败 | 30 只全部失败，未获得可用结果 | 页面级错误态 + “重试全部”主按钮 |

### 全市场选股（WI-006）

| 状态 | 文案基调 | 可操作元素 |
|---|---|---|
| 空 | 选择预设并设置参数以开始筛选 | 预设下拉 + 参数表单 |
| 加载中 | 正在筛选全市场… | 确定态进度 + “停止”按钮 |
| 部分 | 部分板块/行情源不可用，结果基于可得数据 | 结果表角标 + “查看受影响范围” |
| 错误 | 筛选失败：〈分类原因〉 | “重试”按钮 |
| 降级 | 深度指标（如资金流）不可用，排名仅按核心因子计算 | 列头降级角标 + tooltip |
| 已停止 | 已停止，已展示当前已筛结果 | “继续筛选”按钮 |
| 全部失败 | 全市场筛选不可用 | 页面级错误态 + “重试”主按钮 |

### 自选与持仓（WI-007/WI-016）

| 状态 | 文案基调 | 可操作元素 |
|---|---|---|
| 空 | 自选列表为空，添加代码开始跟踪 | “添加自选”按钮 + 从个股分析一键加入 |
| 加载中 | 正在刷新自选行情… | 局部 busy 指示，不阻塞已缓存数据展示 |
| 部分 | 部分持仓行情未刷新，显示为上次已知值 | 过期数据角标 + 每行“重试”图标 |
| 错误 | 刷新失败：〈分类原因〉 | “重试”按钮，保留旧值只读展示 |
| 降级 | 浮动盈亏基于上次成功行情估算 | 数值旁“估算”标签 + tooltip 时间戳 |
| 已停止 | 已取消本次刷新 | “重新刷新”按钮 |
| 全部失败 | 行情源全部不可用，仅显示持仓静态信息 | 页面级降级横幅 + “重试”按钮 |

### 预警（WI-013/WI-014）

| 状态 | 文案基调 | 可操作元素 |
|---|---|---|

| 已停止 | 监控已暂停 | “恢复监控”按钮 |
| 全部失败 | 监控完全不可用，规则暂不生效 | 页面级横幅 + “重试”按钮 |

### 回测比较／独立资金流（WI-015/WI-020）

| 状态 | 文案基调 | 可操作元素 |
|---|---|---|
| 空 | 选择标的与档位开始回测比较 | 标的/档位选择器 + “运行回测”按钮 |
| 加载中 | 正在计算五档回测… | 确定态进度 + “停止”按钮 |
| 部分 | 资金流数据不可用，回测比较结果不受影响（REQ-007） | 资金流区域独立“不可用”角标 |
| 错误 | 回测失败：〈分类原因〉 | “重试”按钮 |
| 降级 | 样本不足，回测结论标注置信度受限 | 结论旁“样本不足”标签 + tooltip |
| 已停止 | 回测已停止 | “继续/重新运行”按钮 |
| 全部失败 | 回测与资金流均不可用 | 页面级错误态 + “重试”主按钮 |

## 关键快捷键

- `Ctrl+Enter` / `F5`：运行当前页主操作。
- `Ctrl+L`：清空输入和结果。
- `Ctrl+Shift+C`：复制当前解释。
- `Esc`：关闭非破坏性对话框/取消菜单；运行任务不允许被无确认强杀。
