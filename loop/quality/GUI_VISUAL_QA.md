# GUI 视觉与可访问性 QA

## 设备矩阵

| 分辨率 | 缩放 | 必须验证 |
|---|---:|---|
| 1366×768 | 100% | 窄桌面、overflow、折叠 Dock、主操作可见 |
| 1920×1080 | 125% | 默认工作台 |
| 1920×1080 | 150% | 长中文和表格列 |
| 2560×1440 | 200% | 高 DPI、图标和字体清晰 |

## 页面/状态矩阵

- 个股：空、输入菜单、分析中、成功、部分失败、历史降级、停止。
- 筛选：六预设、运行中、无匹配、部分深度失败、全市场失败/不完整。
- 组合：空自选、持仓、横向比较、长档位提示。
- 预警：空、规则、触发、监控暂停/恢复。
- 深度：回测不足、资金流成功/失败。
- 对话框：帮助/策略、长章节、验证错误、居中和父窗口关系。

## 字体门禁

- QApplication、每类 QWidget、QPainter 和 HTML 的实际字体为 Microsoft YaHei。
- caption ≥9pt，body/control ≥10.5pt，section 12–14pt，page 16–18pt。
- 不用缩字解决溢出；调整布局、wrap、elide、scroll。

## 几何门禁

- 无裁切、重叠、负尺寸、屏幕外窗口。
- 子窗相对父窗居中，四边留白差 ≤2 DIP（忽略系统边框误差）。
- 内容带水平居中，超宽屏两侧留白对称。
- 普通控件最小 44 DIP；主按钮 48 DIP；标准表格行 48 DIP（用户显式紧凑模式不得低于 40 DIP）。
- 决策强度摘要中心偏差 ≤2 DIP。
- 原生标题栏下不重复 Logo/“股市锦囊”。

## 可访问性

- 键盘可达率 100%，焦点可见。
- 图标动作有 tooltip/accessibleName。
- 文本/背景对比度达 WCAG AA 目标。
- 红绿有文本/符号冗余。
- 屏幕阅读顺序与视觉顺序一致。
