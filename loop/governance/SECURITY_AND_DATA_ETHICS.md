# 安全、数据与伦理

## 数据真实性

- 每个外部结果携带 source、fetched_at、完整度和 stale 状态。
- 实时行情失败不得回退到样例数据。
- 不完整全市场分页必须显式标记或失败，不得当作完整市场。
- 资金流不可用时只显示稍后重试，不影响核心分析。

## 投资边界

- 所有结论是研究辅助，不是确定预测或交易指令。
- UI、导出、说明、回测和持仓计划都保留免责声明。
- 不以收益为唯一工程正确性指标。
- 风险、反例和失败样本必须与正面结果同等报告。

## 安全

- 不在源码、状态、日志或证据中记录密钥、令牌、密码和隐私信息。
- URL、错误与响应摘要需脱敏；仅记录关联 ID 和错误类别。
- 外部响应按不可信输入验证状态、类型、大小、结构、范围和时间戳。
- CSV/HTML 导出必须正确编码和转义，避免公式注入与脚本注入。
- 依赖需要锁定、漏洞扫描、来源和许可证记录。

## 用户配置

- 测试使用 `STOCK_ADVISOR_CONFIG` 指向临时文件。
- 写入使用临时文件 + `os.replace`；失败明确提示且不破坏旧配置。
- 日志不记录完整持仓成本、股数或用户自选清单，除非为本地明确诊断且经用户授权。
