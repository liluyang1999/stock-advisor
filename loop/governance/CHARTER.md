# 工程章程

## 使命

把“股市锦囊”建设为可解释、可复现、可审计、可降级的 A 股研究辅助桌面软件。GUI 采用 PySide6；领域计算保持独立、确定、可测试；任何失败都不得伪装成成功或实时数据。

## 成功定义

1. 所有现有产品功能有明确迁移映射和验收证据。
2. PySide6 UI 在目标 DPI/分辨率上整齐、宽松、可键盘操作。
3. 全局可见文字统一使用 Microsoft YaHei，并验证实际解析字体。
4. 测量、决策、网络、持久化和视图保持清晰边界。
5. 科学计算的公式、单位、适用域、缺失处理和版本可追溯。
6. 网络超时、限流、字段漂移、部分失败、取消和迟到结果都有防御合同。
7. 测试、打包、自检、视觉与性能证据可从源码提交追溯到产物。

## “科学合理”的操作定义

“科学”不等于收益看起来好，而是：

- 输入来源和时间清楚；
- 公式和假设公开；
- 同输入同版本可复现；
- 可以被反例推翻和独立复核；
- 样本、偏差、不确定性和失败结果如实报告；
- 回测无前视泄漏，并包含成本和基线；
- 不把未经校准的分数称为统计置信概率。
