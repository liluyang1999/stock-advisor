# 变更日志

本文件记录"股市锦囊"**产品**（`src/`、`main.py`、`scripts/build_exe.py` 构成的可运行程序）
**面向用户可观察的变更**。格式参照 [Keep a Changelog](https://keepachangelog.com/zh-CN/1.1.0/)，
分节采用 Added/Changed/Fixed/Deprecated/Removed/Security。

版本号采用**两段式 `大版本.小版本`**，规则见 `governance/VERSION_AND_CHANGE_CONTROL.md`：
破坏性变更进大版本，兼容变更进小版本，不设第三段。版本号的唯一权威字段是
`src/version.py::__version__`（ADR-0015 扫平 `src/` 包根后，原 `stock_advisor/__init__.py` 的版本单一真源迁至此）。

`loop/` 控制面自身的变更不改变应用行为，因此不出现在这里；它们记在
`registers/changes.jsonl`（机器可读、逐次追加、带 `evidence_ids`）。一次 `loop/` 文档或治理加固
不必然对应一次产品版本号变化，除非它同时改变了用户可观察的行为或交付合同。

> **位置说明**：本文件原先位于仓库根目录（`../CHANGELOG.md`）。为把全部工程治理文档收拢到
> `loop/` 之下，现合并至此，根目录不再保留副本；`tests/test_version_single_source.py` 的机器
> 强制随之指向本路径。

## [Unreleased]

### Changed

- **运行时数据目录改名**：应用自身的配置与日志目录由 `%APPDATA%\股市锦囊\` 改为
  `%APPDATA%\StockAdvisor\`（`config.json` 与 `logs\`）。现有数据已在改动时原样迁移，用户无需手动操作；
  交付物名称（`股市锦囊.exe`）与界面产品名保持不变。

### Fixed

- **选股不再把半个市场当作全市场**（REQ-026 · WI-033）：全市场快照在后续分页失败时，结果会如实
  标注「非全市场结果」并给出缺了哪几页、实收/应有多少。此前出货版静默地用拿到的那部分排序，
  且报告为完整——用户以为自己在全市场里选股，其实只在残缺样本里。
- **行情请求有总时限**（REQ-025 · WI-033）：一次取数的所有重试与备用源共用一个总预算（20 秒），
  不再每个源各拿一份完整预算。此前个股历史最坏要走 4 个源 × 3 次重试 × 8 秒，取消或关窗时
  界面会长时间没有反应。
- **切档后表格排序与显示一致**：在个股结果表切换决策强度（L1–L5）后，点列头排序不再沿用旧档的
  隐藏排序键，排序顺序与屏上数值一致。
- **慢网下条件预警不再重复触发**：当一轮监控耗时超过轮询间隔时，重叠的周期不再基于同一份旧状态
  重复推送同一条预警。
- **极端金额输入不再抛异常**：界面本金/成本等使用的"安全"金额解析器对超出十进制精度的超大数值
  返回空值而非抛出 `InvalidOperation`，非法输入一律优雅回退。

### Security

- **数据摄取加字节上限**：对行情响应体设读取上限，避免超大或异常的响应把内存撑爆。

### Added

- **个股分析**：一次最多 30 只 A 股代码，批量分析给出买入/持有/卖出倾向、多因子理由、风险与保守
  投入参考；单只失败不中断整批（REQ-001/010 · WI-010）。
- **全市场选股**：六个策略预设（强势动量、放量突破、超跌反弹、低估值蓝筹、高换手活跃、稳健低波动）
  + 可微调参数 + TopN 5–30，结果落在可排序表格上（REQ-002 · WI-013）。
- **五档决策强度**：稳健/稳进/标准/积极/激进。切档只重判不重新联网——客观测量不变，只换决策策略
  （REQ-003 · WI-011）。
- **K 线蜡烛图**：日线蜡烛 + 5/20 日均线 + 成交量，鼠标悬停显示十字光标与当日开高低收
  （REQ-004 · WI-027）。
- **仓位与回测工作台**：按风险预算 + ATR 止损给出股数/止损/止盈/最大亏损；同股历史信号事后复盘
  （REQ-004/021 · WI-012）。
- **自选股与持仓**：可填持仓成本与股数看浮动盈亏，横向对比把已分析的股票放进一张表
  （REQ-005 · WI-015）。
- **条件预警**：价格/涨跌幅/综合分越线提醒，边沿触发，仅程序开启时生效（REQ-006 · WI-016）。
- **个股资金流**：按需查询主力净流入（今日 + 近 5 日），数据源不稳定时提示稍后重试且不影响其它
  功能（REQ-007 · WI-017）。
- **导出与说明**：结果可复制或导出 CSV，随构建生成图文使用说明（REQ-008 · WI-018）。
- **离线自检**：`股市锦囊.exe --self-test` 不联网跑通核心管线并退出 0，用于验证交付物可用
  （WI-024）。
- **发布元数据**：交付物随附 SBOM（CycloneDX 1.5）、第三方许可通知、逐文件 SHA-256 清单，
  `make_release_manifest.py --verify` 可校验一份交付目录是否与清单一致（REQ-029/030 · WI-025）。

### Changed

- **界面框架由 Tkinter 换成 PySide6**（ADR-0001 · WI-023）。`python main.py` 与 `股市锦囊.exe`
  运行的都是 Qt 版；Tkinter 生产层已删除。领域内核（`domain/` 12 个模块）未随之改变，且被门禁静态
  禁止 import PySide6。
- **交付形态由单文件 EXE 改为免安装应用目录** `股市锦囊/`（ADR-0004 · WI-024）。两条理由：单文件每次
  启动都要重新解压约 100 MB 运行时（实测热启动 2.9 s，超出 2.5 s 预算，目录形态为 0.69 s）；且 Qt 以
  LGPL-3.0 分发，其第 4(d) 条要求用户能用自己的 Qt 重新链接，只有 Qt 动态库作为独立文件时才做得到。
  **用户影响：解压后双击目录内的 `股市锦囊.exe` 运行，不再是单个 exe 文件。**
- **金额与行情价改用 `Decimal`（2 位小数）** 承载，数量用 `int`，比率/指标仍用 `float`
  （ADR-0013）。消除了浮点累积误差在盈亏与成本上的显示偏差。
- **运行期新增依赖 PySide6-Essentials**（LGPL-3.0-only）。此前运行期只用标准库。从源码运行需先
  `python -m pip install --group gui`；使用打包交付物的用户无需安装任何东西。

### Fixed

- **补上"宣称已交付却接不通"的功能，共两轮**：第二轮又发现本金/预设从未被界面读写（仓位计算器按写死的
  10 万计算）、条件预警没有任何新建规则的入口因而实际不可用、决策强度光谱算得出却无处显示。均已接通，
  五项配置（自选、本金、档位、预设、预警）现在全部经同一个持有者读-改-写，不会互相覆盖（WI-030）。
- **补上"写好了却点不到"的五个功能**：决策强度切换、证据视图、仓位计算器、自选/持仓横向对比、可信度
  回测的实现与单测早已齐备，但相应部件从未被挂进任何页面（回测在生产代码里更是零调用），因此在此前的
  构建里用户根本用不到。现已全部接通，并新增一条装配级守卫：从装好的主窗往下找，凡本文件宣称已交付的
  功能部件都必须可达，否则构建失败（WI-029）。
- **迟到结果不再覆盖新状态**：取消或重新发起后，上一轮的进度/单项/完成结果一律丢弃，不会把旧股票的
  数据显示在新股票名下（RISK-005 · WI-019）。
- **分页残缺不再静默**：全市场快照在后续页失败时会如实报告缺了哪几页与实收/应有数量，不再把半个
  市场当作完整市场交给选股排序（REQ-026 · WI-026）。
- **网络失败不再伪造回退值**：失败路径结构上不携带数据，界面显示可见的降级原因而不是编造的数字
  （REQ-024 · WI-020）。
- **字体缺失可见**：目标机没有 Microsoft YaHei 时如实报告实际解析到的字体或给出提示，不静默换字体
  （REQ-033 · WI-021）。

### Security

- **导出注入中和**：CSV 与剪贴板导出对以 `=`、`+`、`-`、`@` 开头的单元格值做中和，避免表格软件把
  导出内容当公式执行（REQ-032 · WI-028）。
- **日志不记录敏感内容**：结构化日志只写声明过的字段，原始报文、完整自选股/持仓与凭证不入日志
  （ADR-0011 · WI-020）。
- **免责声明常驻**：所有结果视图、生成的说明书与每一份导出都带非投资建议声明（REQ-031 · WI-011）。
