# 威胁模型

| 威胁 | 影响 | 控制 |
|---|---|---|
| 恶意/异常行情 payload | 崩溃、错误决策 | 长度/结构/范围验证，纯解析，失败关闭 |
| CSV 公式注入 | 打开导出时执行公式 | 前缀危险单元格、测试 Excel 语义 |
| HTML 注入 | 说明/报告脚本风险 | HTML 转义，禁止原始外部文本 |
| 配置损坏/竞争写 | 用户数据丢失 | 原子替换、schema、备份/错误状态 |
| 依赖供应链 | 恶意代码/漏洞 | 精确锁定、哈希、来源、SBOM、扫描 |
| Qt 插件劫持 | 加载错误 DLL/plugin | 受控搜索路径、干净打包、插件清单 |
| 路径遍历/任意写 | 覆盖项目外文件 | 路径解析与项目边界、用户选择确认 |
| 日志泄露持仓 | 隐私风险 | 结构化脱敏、最小日志 |
| 迟到结果 | 错误 UI/决策 | generation/task_id 校验 |
| 虚假降级 | 用户误判 | 禁止样例冒充、可见 provenance |

发布前做 STRIDE 复核、依赖漏洞/许可证检查、导出编码测试和 Windows DLL/plugin 搜索路径验证。
