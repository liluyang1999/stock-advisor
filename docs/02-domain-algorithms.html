02 · 指标、决策与回测

技术指标怎么算、五档决策强度如何把客观测量翻译成建议、仓位与回测的数学

← 首页 · ← 上一篇：分层架构
先把话说清楚：下面所有公式、阈值与权重都是这个程序的实现细节， 用来说明「代码在做什么」。它们不是投资方法论，更不构成投资建议。 规则型模型的本质是把一组可解释的经验规则写成可复现的代码，它无法预测未来。

一、技术指标层

全部在 src/domain/engine.py，都是纯函数：输入一个数组，输出一个数或 None。

移动平均 MA

moving_average(values, window)  # 最后 window 个值的算术平均

样本不足 window 时返回 None，不是用现有数据凑一个近似值。 这是贯穿全项目的「零伪造」在算法层的体现：数据不够就说不够。

指数移动平均 EMA 与 MACD

EMA_t = price_t × α + EMA_{t-1} × (1 − α)，其中 α = 2 / (period + 1)
MACD  = EMA(12) − EMA(26)
Signal = EMA(MACD 序列, 9)
Hist  = MACD − Signal
实现要点：算 Signal 需要 MACD 的历史序列，而不是只有当前值。 代码里 _ema_series() 先算出 EMA12 与 EMA26 的完整序列，逐点相减得到 MACD 序列， 再对它求 EMA。若偷懒只用当前 MACD 值，Signal 根本无从算起——这是初学者最常写错的地方。

RSI（相对强弱）

RS  = 平均涨幅 / 平均跌幅（period 内）
RSI = 100 − 100 / (1 + RS)
退化情形本实现的返回为什么
全程无下跌100分母为 0，数学上 RSI 趋于 100
全程无上涨0同理
价格完全不动50涨跌都是 0，视为中性，而不是 0/0 崩溃
样本不足 period+1None不够就是不够

布林带位置 Bollinger Position

mid = MA(window)，σ = 总体标准差
upper = mid + 2σ，lower = mid − 2σ
position = (last − lower) / (upper − lower)   # 归一化到 0..1

0 表示贴着下轨、1 表示贴着上轨、0.5 是中轨。当 σ = 0（价格完全不动）时返回 0.5， 而不是让 0/0 抛异常——这类退化输入在真实行情里会出现（停牌、一字板）。

ATR%（真实波动幅度百分比）

TR = max(高−低, |高−昨收|, |低−昨收|)      # 真实波幅，考虑跳空
ATR = TR 的 period 日平均
ATR% = ATR / 最新价 × 100
ATR 后面会直接决定止损距离和仓位大小，是本项目里最「有用」的一个指标。 它的意义是「这只股票平常一天大概动多少」——止损设得比常态波动还窄，就是在给自己制造无谓的止损出局。

二、测量层：measure()

measure(quote, history) 把上面的指标汇总成一个 Measurement。它与决策档位完全无关—— 同一只股票，无论你是保守派还是激进派，客观测量是同一份。

八个打分因子

因子看什么
_score_moving_averages价格与 5/20/60 日均线的相对位置、均线多头/空头排列
_score_trendMACD 金叉/死叉、柱状体方向
_score_momentumRSI 区间、近 5 日胜率、最大回撤
_score_volume量比、放量/缩量与价格方向是否配合
_score_intraday当日收在振幅区间的什么位置（收在高位还是低位）
_score_bollinger通道位置：贴上轨/贴下轨/中枢
_score_support_resistance距离近期支撑位与压力位的远近
_score_volatilityATR% 是否过高（波动太大扣分）

每个因子返回得分 + 人话理由 + 风险提示。「人话理由」是这个产品的核心卖点之一： 界面上每条结论都能展开看到它是由哪些因子、以什么理由得出的——这就是「可解释」的含义。

风控扣分与把握程度

base_factor_sum  = 八个因子得分之和
risk_penalty     = 负数，来自 ST 标记、极端波动、流动性不足等
confidence       = 由综合分、历史长度、指标齐备度共同决定（0..100）

三、决策层：五档决策强度

这是本产品最有辨识度的设计。同一份客观测量，五种决策口径：

档位买入线
t_buy		卖出线
t_sell		 风控权重
risk_weight		买入把握门槛
confidence_gate		 风险预算
risk_budget		仓位上限
position_cap
L1 稳健+40−151.6700.5%30%
L2 稳进+33−191.3600.75%45%
L3 标准+25−251.0不设1%60%
L4 积极+18−330.8不设1.5%75%
L5 激进+12−420.6不设2%90%
怎么读这张表：越稳健的档位，买入线越高（要更强的信号才肯买）、 卖出线越靠近 0（稍有不妙就减仓）、风控扣分权重越大（对风险更敏感）、 仓位上限越低。L1 还额外要求把握程度 ≥ 70 才允许买入——信号够强但把握不足时，它选择观望。

决策分：policy_score

score = base_factor_sum + risk_penalty × risk_weight
if 历史长度 < 30 天:  score × 0.75      # 样本不足，降低置信
score = clamp(score, −100, +100)

注意 L3 的 risk_weight 恰好是 1.0，所以 L3 的决策分就等于客观综合分—— 「标准档」在设计上就是那个不加偏置的参考点。

从分数到动作

score ≥ t_buy   →  BUY   （L1/L2 还要过 confidence_gate，否则降级为 HOLD）
score ≤ t_sell  →  SELL
其余             →  HOLD

四、仓位测算：把「建议」变成可执行的数字

光说「买入」没有用，用户真正需要的是买多少。这一步用的是风险预算法：

止损距离 stop% = clamp(1.8 × ATR%, 2%, 12%)

强度系数 strength = clamp(|score| / 55, 0.4, 1.0)
把握系数 conf     = clamp(confidence / 100, 0.5, 1.0)

投入比例 = (risk_budget / stop%) × strength × conf
投入比例 = min(投入比例, position_cap)
这个公式的直觉：「我这一笔最多亏本金的 risk_budget（如 1%）」。 如果止损距离是 5%，那么投入比例 = 1% / 5% = 20% 的本金——这样即使真的止损出局， 总亏损也就是本金的 1%。波动越大的股票，止损必须放得越宽，因而仓位必须越小， 这正是 ATR 在这里的作用。最后再乘以信号强度和把握程度做微调，并被档位的仓位上限封顶。

最终 position_plan() 输出：建议股数（按 A 股 100 股一手取整）、止损价、止盈价、 最大亏损金额。所有金额用 Decimal 参与计算（见 第 05 篇）。

五、可信度回测

backtest_signals() 回答一个诚实的问题：这套规则在这只股票的历史上，表现如何？ 

对历史上每一天 i：
    只用第 i 天及之前的数据 → 生成当时的信号
    看第 i+N 天的价格 → 计算这个信号的前瞻收益
最容易犯的错误：前视偏差（look-ahead bias）。 如果算第 i 天信号时不小心用到了第 i+1 天的数据，回测结果会好得离谱，而实盘一败涂地。 本项目为此写了专门的防前视测试：把序列截断到第 i 天算一次，再用完整序列算一次， 两者在第 i 天的结论必须一致。指标是纯函数、没有隐藏状态，这条性质才有可能成立。

回测还会在样本不足时明说「样本不足」，而不是用三五个样本硬算出一个胜率给用户看。 界面上这条信息是显示出来的，不是悄悄藏起来。

六、全市场选股

选股（screener.py）与个股分析是两条不同的路径：

个股分析全市场选股
数据实时行情 + 历史日线（每只单独取）一次快照拉全市场（分页）
深度八因子 + 指标 + 回测先按快照字段硬性过滤，再打分排序
可选深度分析—对 TopN 再跑一次完整个股分析

硬性过滤与打分

apply_filters(snapshots, criteria)   # 价格/涨跌幅/换手/量比/市值/PE/PB… 区间过滤
rank(filtered, objective)            # 按目标（动量/突破/超跌…）打分排序
区间端点是闭区间（含端点）：price_min=10.0 时价格正好 10.00 的股票会被保留。 字段缺失（东财返回 "-"）时，若该端设了边界则判为不通过—— 宁可漏掉，也不把一只连数据都没有的股票推荐给用户。

六个策略预设

强势动量、放量突破、超跌反弹、低估值蓝筹、高换手活跃、稳健低波动。每个预设是一组 「过滤条件 + 排序目标 + 可调参数」的组合，用户还能微调其中的关键参数（如成交额下限、TopN）。

本篇要点回顾

  • 指标全是纯函数，样本不足或退化输入一律返回 None 或中性值，绝不硬凑。
  • 测量与决策分离：measure() 客观、decide() 带档位偏好；L3 的风控权重为 1.0，是不加偏置的参考点。
  • 仓位用风险预算法：波动越大 → 止损越宽 → 仓位越小，让单笔最大亏损可控。
  • 回测必须防前视偏差，并在样本不足时明说。
  • 选股的区间过滤是闭区间，缺失字段在设了边界时判不通过。
