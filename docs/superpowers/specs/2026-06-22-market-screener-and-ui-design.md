# A股策略助手 — 全市场选股推荐 + UI 居中布局 设计

> 本设计在既有「个股分析」基础上，新增「全市场选股推荐」，并按硬性 UI 布局要求重构界面；同时修复构建与代码缺陷、补齐项目指导文档。交付物仍为单文件 EXE `A股策略助手`。

## 目标

1. **实时全市场自主选股推荐**：扫描当前行情下的全 A 股，按用户选定的「证券特征范围」自动推荐股票，并对入选股做与现有引擎一致的买/持/卖深度判断。
2. **UI 空间布局硬性要求**：所有窗体必须在主窗口（主窗口相对屏幕）居中显示；四边留白均匀；任何组件不得单边过长；内容须均匀显示在正中间。
3. **查缺补漏**：修复构建输出越界、北交所代码误判等缺陷。
4. **指导性内容**：补齐 README、AGENTS、HTML 使用说明。
5. **全面测试**：纯逻辑 TDD 全覆盖，现有 44 测试保持全绿。

## 约束（沿用既有）

- 运行期只依赖 Python 标准库；构建期只允许 `pip install pyinstaller`。
- 不引入 Node/.NET/浏览器框架或非 Python 工具链。
- 交付物：项目内 `outputs/` 下的单文件 `A股策略助手.exe` 与 HTML 说明书。

## 用户已确认的范围决策

- 交互：**策略预设 + 关键参数微调**（非全手动筛选器）。
- 深度：**对入选 Top N 拉 K 线跑现有引擎**，给买/持/卖 + 理由。
- 特征范围：**v1 只上一次性可靠拿到的特征**；资金流/基本面留二期。

## 数据基础（已实测确认）

东方财富 `push2.eastmoney.com/api/qt/clist/get` 单次调用即可返回全 A 股（实测 5865 只）快照，字段：
`f12`代码 `f13`市场(1=沪,0=深/北) `f14`名称 `f2`最新价 `f3`涨跌幅% `f4`涨跌额 `f5`成交量 `f6`成交额 `f7`振幅% `f8`换手率% `f9`市盈率TTM `f10`量比 `f20`总市值 `f21`流通市值 `f22`涨速 `f23`市净率 `f24`60日涨幅% `f25`年初至今涨幅%。
注意：PE 可能为负（亏损股）；920xxx 为北交所新代码段；`fs` 市场段：`m:0+t:6`(深主板) `m:0+t:80`(创业板) `m:1+t:2`(沪主板) `m:1+t:23`(科创板) `m:0+t:81+s:2048`(北交所)。

## v1 证券特征（全部来自一次 clist 调用）

- **范围限定**：板块多选（沪主板/深主板/创业板/科创板/北交所）、剔除 ST/退市风险（名称含 ST/\*ST/退）、价格区间、成交额下限（流动性门槛）、总市值/流通市值区间。
- **行情**：当日涨跌幅、振幅、换手率、量比、涨速。
- **多周期动量**：60 日涨幅、年初至今涨幅。
- **估值**：市盈率 PE（含「剔除亏损/负 PE」开关）、市净率 PB。

二期（不在 v1）：资金流向（主力净流入需额外接口）、基本面（ROE/利润增速/营收增速）、行业概念筛选、技术形态批量预筛（v1 通过对 Top N 深度分析间接覆盖技术面）。

## 排序目标与策略预设

排序目标（对过滤集打分排序）：`momentum`(动量) `value`(价值) `activity`(活跃) `breakout`(放量突破) `rebound`(超跌企稳) `balanced`(综合稳健)。

6 个预设（每个 = 一组 FilterCriteria + 一个排序目标 + 暴露 2–4 个可微调关键参数；TopN 默认 20，深度分析默认开）：

1. **强势动量** momentum：涨幅 2~7%、量比≥1.2、成交额≥1 亿、60 日>0、剔除 ST。
2. **放量突破** breakout：涨幅 1~9%、量比≥1.8、换手 3~25%、成交额≥2 亿。
3. **超跌反弹** rebound：今日涨幅≥-3%（企稳）、60 日≤-15%、年初至今<0、剔除 ST。
4. **低估值蓝筹** value：PE 0~20、PB 0.5~3、总市值≥200 亿、成交额≥1 亿。
5. **高换手活跃** activity：换手 5~30%、量比≥1.5、价格 3~60。
6. **稳健低波动** balanced：振幅≤4%、换手 1~8%、总市值≥100 亿、PE 0~30。

## 数据流

1. `fetch_market_snapshot()` 分页拉全市场（pz 分页，复用重试，多页拼接）。
2. `apply_filters(snapshots, criteria)` 按硬性范围过滤；板块由 `f13`+代码段推断，剔除 ST 按名称。
3. `rank(filtered, objective)` 按目标打分排序，取 TopN。
4. 若深度开：对 TopN 用 `symbol_from_market` 构造 `StockSymbol` → 跑现有 `analyze_symbol`，得到 `AnalysisResult`；单只失败则以快照降级展示并标注。
5. 进度回调逐只回传；可取消。

## UI 设计（双标签页 + 居中均匀布局）

- 顶部 `ttk.Notebook`：**「个股分析」(原功能原样保留) / 「全市场选股」(新)**。
- **居中与均匀留白（硬性要求）**，抽成纯函数便于测试：
  - `compute_centered_geometry(outer_w, outer_h, win_w, win_h) -> (x, y)`：窗体在父/屏幕内居中，四边由 `(outer-win)/2` 对称留白。
  - `compute_content_band(viewport_w, max_content_w, min_margin) -> (x_offset, content_w)`：内容列限制最大宽度并水平居中，左右留白相等；避免内容随窗口拉伸到单边过长。
  - 外层 padding 四边对称；主窗口相对屏幕居中，子窗口相对主窗口居中。
  - 内容最大宽度 `MAX_CONTENT_WIDTH`（约 1100px）；超宽屏时两侧均匀留白。
- 选股页组件：预设卡片行（6 个）→ 关键参数微调区（当前预设的 2–4 个阈值 + TopN + 深度分析开关）→ 「开始选股」→ 复用现有结果表格 / 可视化仪表 / 详情面板 / 复制导出。
- 两阶段进度：阶段一（拉全市场+筛选，秒级）→ 阶段二（深度分析 N/N，可取消）。

## 错误处理（延续诚实风格）

- 全市场拉取失败：明确报错，不伪造推荐。
- 过滤结果为空：友好提示「没有符合条件的股票，请放宽筛选范围」。
- 单只深度分析失败：以快照信息展示并标注，不影响其他。
- 负/零 PE 视为「亏损」，可被「剔除亏损」开关过滤；区间过滤对缺失值采取明确策略（缺失不通过数值区间，除非该项未启用）。
