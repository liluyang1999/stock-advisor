# 股市锦囊交付收敛设计

## 背景

`股市锦囊` 已具备个股分析、全市场选股、自选股/持仓、横向对比、条件预警、资金流查询、说明文档、单文件 EXE 打包与自检能力。当前阶段的目标不是继续扩展功能，也不是追求早期渲染图的完整视觉复刻，而是把现有功能模块收敛到可以交付普通用户正常使用的状态。

本轮工作遵循项目硬约束：运行期只使用 Python 标准库；不引入 Node、Electron、浏览器框架或运行期第三方依赖；交付物保持 `dist/股市锦囊.exe` 和 `dist/使用说明.html`；测试不得写入真实 `%APPDATA%`。

## 收敛顺序

### 阶段 A：交付阻断审计与定点修复

优先处理会直接影响用户正常使用或交付可信度的问题：

1. 运行、停止、清空、关闭、后台线程、监控预警的状态一致性。
2. 输入、配置保存、复制、导出、弹窗、资金流、选股结果等用户可见错误处理。
3. 数据源失败、缺失字段、非法数值、空结果、部分失败结果的明确呈现。
4. 打包、自检、说明书生成、中文软件名与交付文件名的一致性。

阶段 A 只修阻断项和明显误导项。除非修复阻断项确实需要，否则不拆大模块、不改算法目标、不增加新功能、不替换 UI 技术栈。

### 阶段 C：UI 视觉与布局收尾

阶段 A 完成后，再做视觉收尾：

1. 确认主窗口和子窗口都保持居中、均匀留白、内容最大宽度约束。
2. 确认界面名称固定为 `股市锦囊`，不受旧渲染图或内部英文构建名影响。
3. 控件密度保持工具型、克制、可扫描，不新增臃肿卡片或装饰性组件。
4. 检查按钮、菜单、表格、摘要区、图表、弹窗之间的样式一致性。
5. 使用真实桌面截图复核首屏和关键弹窗，必要时只做小范围布局/文案修正。

阶段 C 不追求大视觉重做，不做营销页，不引入图片或动画资产来装饰工具界面。

### 最终复盘

完成 A 和 C 后，做一次全局复盘：

1. 对照项目约束、功能模块和交付物逐项检查。
2. 运行完整验证门禁。
3. 确认遗留风险是否已降到可交付范围。
4. 只有在证据覆盖全部显式要求时，才判断目标完成。

## 模块验收口径

### 核心逻辑

`symbols.py`、`screener.py`、`presets.py`、`engine.py`、`policy.py`、`backtest.py`、`chart.py`、`compare.py`、`alerts.py` 保持纯逻辑边界，不引入网络或 tkinter。关键边界包括非法股票代码、缺失行情字段、NaN/Inf、空历史、无候选结果、预警边沿触发与复位。

验收证据：相关单测覆盖并通过，全量 `unittest` 通过。

### 数据与工作流

`data_provider.py` 是唯一网络模块；接口失败必须返回明确错误，不伪造行情或建议。`workflow.py` 负责把 provider 异常转成 UI 可展示结果，后台线程不得裸异常导致界面卡死。

验收证据：provider/workflow 测试通过；后台 worker 异常路径有 GUI 测试覆盖。

### 持久化

配置只写 `%APPDATA%\股市锦囊\config.json` 或测试环境变量指定路径。读取损坏配置、保存失败、不可写路径都不能崩溃；用户可见动作保存失败时必须有明确反馈。高频偏好项使用状态栏提示，明确保存动作使用弹窗提示。

验收证据：store 测试和 GUI 保存失败测试通过。

### 桌面 UI

`app.py` 只负责界面、线程调度与渲染；可测的格式化、几何、图表和文案函数保持模块级测试。运行中不得允许会造成状态误导的输入变更；关闭窗口必须收口后台状态；空闲态停止不得产生误导状态。

验收证据：GUI headless 测试覆盖运行、停止、清空、关闭、监控、复制、导出、结果选择与弹窗。

### 交付物

构建只写项目内 `build/` 与 `dist/`。最终交付物必须为 `dist/股市锦囊.exe` 和 `dist/使用说明.html`。EXE 自检必须退出码 0 并输出 `SELF_TEST_OK`。

验收证据：`python build_exe.py` 成功；`dist\股市锦囊.exe --self-test` 成功；`dist` 文件名和时间戳确认。

## 最终验证门禁

每轮修复后至少运行受影响测试。最终复盘前必须运行：

1. `python -m unittest discover -s tests`
2. `python -m py_compile main.py build_exe.py src/stock_advisor/*.py`（在 PowerShell 中使用显式文件展开）
3. `git diff --check`
4. `python build_exe.py`
5. `dist\股市锦囊.exe --self-test`
6. 必要时启动桌面版并截图复核 UI 名称、布局和组件协调性

## 明确不做

1. 不新增投资预测能力或收益承诺文案。
2. 不引入运行期第三方依赖。
3. 不迁移到 Electron、Web、Node、.NET 或其它 UI 技术栈。
4. 不进行大规模算法重写、架构重做或视觉重设计。
5. 不把构建产物写到项目外。
6. 不为了通过测试删除、跳过或弱化现有测试。

## 完成定义

本收敛工作完成的标准是：阶段 A 的交付阻断项没有未处理的当前证据，阶段 C 的视觉协调性经过截图或等价方式复核，所有最终验证门禁通过，交付物名称与软件名称均为 `股市锦囊`，并且所有剩余问题都不影响普通用户正常安装、启动、分析、选股、查看说明、保存配置和退出程序。
