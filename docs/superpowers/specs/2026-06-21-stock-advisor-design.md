# A股策略助手设计说明

## 目标

构建一个可直接运行的 Windows EXE 小软件，用于输入一个或多个国内证券市场股票代码后，给出当日偏多、偏空或观望/持有的模型建议。程序需要界面简洁，但后台逻辑不能只是静态规则；它应结合实时行情、历史K线、技术指标、风险约束和数据质量，生成可解释的建议。

## 约束

- 技术栈只使用 Python。
- 应用运行逻辑只依赖 Python 标准库。
- 打包工具如需安装，只允许通过 `pip install` 安装到本机 Python 环境。
- 不引入 Node、.NET、Electron、浏览器框架或外部非 Python 工具链。
- 交付物放在当前目录的 `outputs` 目录下，包括 EXE 和 HTML 说明书。

## 推荐方案

采用 Python + Tkinter + 标准库网络请求 + PyInstaller 打包。

方案优点：

- Tkinter 随 Python 发行版提供，适合简洁桌面界面。
- 标准库 `urllib` 可完成公开行情接口访问，不增加运行时依赖。
- 核心预测逻辑可通过单元测试覆盖，和界面分离。
- PyInstaller 是 Python 生态打包工具，满足只用 Python 相关工具链的限制。

不采用的方案：

- Electron/网页桌面壳：界面更现代，但违反只用 Python 相关技术栈。
- .NET/WinForms/WPF：打包方便，但违反技术栈限制。
- 重型量化框架：依赖复杂，安装和可复制性不适合小软件交付。

## 架构

程序分为五个边界清晰的模块：

- `models.py`：定义股票代码、行情、K线、指标、建议结果等数据结构。
- `symbols.py`：解析和规范化用户输入的 A 股代码，推断交易所和行情接口 `secid`。
- `data_provider.py`：使用东方财富公开行情接口获取实时行情和历史日线；失败时返回明确错误。
- `engine.py`：计算 RSI、均线、趋势、量能、波动、日内位置和风险分数，输出买入/卖出/持有建议。
- `app.py`：Tkinter 桌面界面，只负责输入、展示、后台线程调度和错误提示。

## 数据流

1. 用户输入股票代码，可用空格、逗号、分号或换行分隔。
2. `symbols.py` 清洗和规范化代码，例如 `600519` -> `sh600519`、`000001` -> `sz000001`。
3. `data_provider.py` 获取实时行情和最近 120 个交易日 K 线。
4. `engine.py` 将行情和历史数据合成指标：
   - 均线位置：最新价相对 MA5、MA20、MA60。
   - 趋势斜率：MA5/MA20 的短中期方向。
   - 动量 RSI：识别超买、超卖和中性动量。
   - 日内位置：当前价在当日高低区间中的位置。
   - 量能确认：最新成交量相对近20日均量。
   - 风险惩罚：大幅高开、过高振幅、接近跌停、趋势背离等。
5. 引擎输出 `BUY`、`SELL` 或 `HOLD`，并附带置信度、分数、关键理由和风险提示。

## 决策规则

建议不是投资承诺，而是模型倾向：

- 总分 `>= 25`：买入倾向。
- 总分 `<= -25`：卖出或减仓倾向。
- 其余：继续持有/观望。

置信度由数据质量和分数强度共同决定。若行情或历史数据不足，置信度自动下降，建议偏保守。

## 错误处理

- 股票代码格式错误：在界面明示错误，不发起网络请求。
- 行情接口失败：展示网络或接口错误，不伪造建议。
- 历史数据不足：仍可用实时行情给出保守判断，但降低置信度并展示风险提示。
- 单只股票失败不影响其他股票分析。

## 验证

核心逻辑使用 Python 标准库 `unittest` 覆盖：

- 股票代码规范化和输入拆分。
- 行情接口 JSON 解析。
- RSI、均线、量能、风险评分。
- 买入、卖出、持有三类建议路径。

最终交付前执行：

- `python -m unittest discover -s work/stock_advisor/tests -v`
- `python -m py_compile` 检查源码语法。
- PyInstaller 构建 EXE。
- 运行 EXE 的 `--self-test` 模式确认打包程序可启动并执行核心逻辑。
