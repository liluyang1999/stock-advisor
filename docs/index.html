股市锦囊 · 知识库

本机计算、行情按需联网的 A 股桌面辅助工具：从架构到算法、从界面到测试的教学材料

这份知识库把读懂「股市锦囊」需要的主要知识点拆开讲：它为什么这样分层、 每个指标怎么算、Qt 的线程边界为什么必须这样划、金额为什么不能用 float、 打包为什么选 onedir 而不是 onefile、以及一套「文档不许和代码说不一样话」的工程治理是怎么运转的。

它不是 API 手册。每一节都尽量回答三个问题：这是什么、为什么这么选、 不这么做会出什么事——第三个问题往往最有价值，因为项目里的多数设计都是被真实的坑逼出来的。

阅读路径

按顺序读能建立完整认知；按需查阅也可以，各页自成体系。

01 · 地基

分层架构与依赖方向

纯领域内核、端口与适配器、四层依赖单向流动，以及「让机器守住架构」的静态门禁。
02 · 算法

指标、决策与回测

MA/RSI/MACD/布林/ATR 怎么算，五档决策强度如何把客观测量翻译成建议，仓位与回测的数学。
03 · 框架

PySide6 框架基础

Qt 为什么这样设计：对象树与内存、信号槽与连接类型、事件循环、模型/视图、QSS、打包要点。
04 · 界面

本项目的界面实现

五页导航、模型/视图的实际选型与偏离理由、设计 token、K 线自绘、空态与失败态、可访问性。
05 · 并发

线程、取消与世代守卫

GUI 线程为什么不能碰网络、迟到结果如何丢弃、协作取消与总 deadline 的合同。
06 · 数据

行情数据与数值纪律

多源回退、解析鲁棒性、分页完整度、零伪造原则，以及 Decimal / int / float 的三分法。
07 · 工程

测试、门禁与交付

TDD 的真实用法、八道质量门禁、loop 控制平面、CI 的坑、PyInstaller 打包与发布元数据。
08 · 附录

技术栈整体报告

按操作链路串起技术栈、源码职责与实现边界，作为通读材料，并链接到各主题的详细说明。
09 · 动手复盘

学习复盘与常见问题

从输入到结果走一遍：验收窄窗、清空与切档，读懂数据缺失，隔离测试并清理自己的临时产物。
10 · 独立交付

从源码到独立应用

依赖哈希锁、隔离构建、失败恢复、独立运行验证与清理。
怎么选：01–07 按主题讲解，08 是通读附录，09 帮你动手检查理解，10 串起独立交付流程。 教材都随源码维护；发现差异时，应对照实现与工程记录核实，不把旧文章当成当前行为的保证。

快速上手：先把它跑起来

读之前先跑一遍，后面每一篇都会好懂很多。需要 Python 3.14+； 依赖安装通常需要联网；装好以后，自检与替身测试可离线运行。 真实行情查询需要联网；打开空白界面并不代表已获得最新数据。 

# 1. 在配置好的 Python 环境里安装 GUI 与测试依赖（通常联网）
python -m pip install --group gui

# 2. 启动图形界面
python main.py
#    Windows PowerShell 也可用一键脚本： .\run.bat

# 3. 离线自检：不联网跑通「分析 → 五档决策 → 仓位 → 回测 → 选股」全链路
python main.py --self-test
#    成功会打印 SELF_TEST_OK ... checks=8/8 并以退出码 0 结束

想进一步动手：

# PowerShell：在测试终端运行
$env:PYTHONDONTWRITEBYTECODE = '1'
$env:QT_QPA_PLATFORM = 'offscreen'
python -B -m unittest discover -s tests
python -B -m unittest discover -s tests -p test_docs.py

# 在另一个终端截图：使用演示数据，不调用行情接口；核对各状态与配置隔离
python scripts/capture_ui.py --states success fail empty

# 提交源码后，隔离构建并验证完整交付目录
.\build.bat      # Windows PowerShell；首次构建可能安装依赖
数据与配置存在哪：自选股、本金、档位、预设、预警规则存在 %APPDATA%\StockAdvisor\config.json，日志在同目录的 logs\ 下。 测试与截图应使用临时配置，并在关闭窗口与后台任务后回收自己的临时文件。 具体边界见测试隔离与清理。

这个产品长什么样

贯穿全项目的一条立场：本产品是可解释的辅助判断工具，不构成投资建议。 关键结果视图、生成说明书和导出有回归测试检查这一边界；新增界面仍需补查。 技术上还要守住「零伪造」原则：取不到数据就如实报错，绝不用回退值假装有结果。
