股市锦囊 · 知识库

一个离线、规则驱动的 A 股桌面决策支持工具，从架构到算法、从并发到打包的完整教学材料

这份知识库把「股市锦囊」这个真实项目里用到的全部知识点拆开讲：它为什么这样分层、 每个指标怎么算、Qt 的线程边界为什么必须这样划、金额为什么不能用 float、 打包为什么选 onedir 而不是 onefile、以及一套「文档不许和代码说不一样话」的工程治理是怎么运转的。

它不是 API 手册。每一节都尽量回答三个问题：这是什么、为什么这么选、 不这么做会出什么事——第三个问题往往最有价值，因为项目里的多数设计都是被真实的坑逼出来的。

快速上手：先把它跑起来

读之前先跑一遍，后面每一篇都会好懂很多。需要 Python 3.14+； 下面的命令都不联网也能跑（自检与测试自带离线样例数据）。 

# 1. 装唯一的运行期依赖（PySide6-Essentials，约 200 MB）
python -m pip install --group gui

# 2. 启动图形界面
python main.py
#    或用一键脚本： run.bat（Windows） / ./run.sh（Git Bash、WSL）

# 3. 离线自检：不联网跑通「分析 → 五档决策 → 仓位 → 回测 → 选股」全链路
python main.py --self-test
#    成功会打印 SELF_TEST_OK ... checks=8/8 并以退出码 0 结束

想进一步动手：

# 跑测试（约 900 个用例，界面测试用 offscreen，无需显示器）
python -m pip install --group dev
python -m unittest discover -s tests

# 把五个页面逐页截图，看版式效果（自带假数据，不联网、不碰你的配置）
python scripts/capture_ui.py --states success fail empty

# 打包成免安装应用目录（自动装构建依赖 PyInstaller）
build.bat        # 或 ./build.sh
数据与配置存在哪：自选股、本金、档位、预设、预警规则存在 %APPDATA%\StockAdvisor\config.json，日志在同目录的 logs\ 下。 测试与截图工具都指向临时目录，不会动你的真实配置。

这个产品长什么样

贯穿全项目的一条立场：本产品是可解释的辅助判断工具，不构成投资建议。 这不只是一句免责话术，它是有机器强制的设计约束——所有结果视图、生成的说明书、每一份导出都必须带这句话， 少一处，测试就红。技术上它对应「零伪造」原则：取不到数据就如实报错，绝不用回退值假装有结果。
